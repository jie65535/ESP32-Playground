## Platformer assets and data

The Platformer implementation includes generated C++ arrays derived from the
[Gold872/Super-Mario-Bros](https://github.com/Gold872/Super-Mario-Bros) and
[justinmeister/Mario-Level-1](https://github.com/justinmeister/Mario-Level-1) fan
projects, including Mario-themed names, level data, and pixel art. The exact
source commits are documented in `docs/experiments/020_platformer_game.md`,
`021_platformer_campaign.md`, and `022_platformer_reference_parity.md`. Any
license on those reference projects' source code does not grant rights to
Nintendo trademarks or copyrighted game art. These files are therefore excluded
from the root MIT grant and require a separate redistribution decision.

## Model and data

The TinyLM software import is MIT-licensed, but training data, generated model
weights, tokenizer files, and derived vocabulary may have separate terms. The
repository intentionally excludes the large dataset and `model.bin`; review the
dataset's own terms before publishing or sharing any generated artifacts.
