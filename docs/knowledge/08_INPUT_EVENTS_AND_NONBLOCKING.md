# 输入事件与非阻塞状态机

## 统一输入入口

键盘快捷键、USB CDC 命令和未来 Wi-Fi 命令都应转换为统一事件或命令，例如 `PageDisplay`、`ColorTest`、`Screenshot`。页面和外设逻辑只处理事件，不关心命令来自哪个输入通道。

## 如果以后增加实体按键

- 外接按键通常使用内部上拉、按下低有效，但仍要以实际接线为准。
- 去抖至少需要稳定时间；当前经验值是约 30ms。
- 短按在释放时触发，长按达到阈值后只触发一次，并抑制释放时的短按。
- 显示休眠后的首个按键只负责唤醒，不叠加导航动作。

## 非阻塞原则

- 不在 `loop()` 中使用长时间 `delay()` 等待 Wi-Fi、串口、I²C 或动画。
- 使用 `millis()` 差值、状态枚举和事件时间戳推进工作。
- 动效可被输入、链路变化或新数据立即打断。
- 日志、截图、网络包和显示刷新要明确互斥边界，避免互相抢占同一缓冲。
