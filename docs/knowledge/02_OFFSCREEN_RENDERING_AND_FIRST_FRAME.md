# PSRAM 离屏渲染与首帧背光

## 问题

直接对 TFT 依次执行清屏、画矩形、画文字，会把中间过程显示出来，表现为闪烁或“白闪”。MCU 复位时 ILI9341 还可能保留上一帧 GRAM，背光过早点亮会把旧画面照出来。

## 已验证方案

- 320×240、RGB565 单帧需要 `320 × 240 × 2 = 153600` 字节，放在 PSRAM。
- 用一个 `TFT_eSprite` 完整绘制一帧，再一次 `pushSprite(0, 0)`。
- LCD 初始化前、首帧推送前保持 GPIO45 背光低电平。
- 普通刷新整帧推送；以后做切页动效时可以只推送离屏画布的区域，不增加第二个全屏缓冲。

## 运行时规则

1. `pinMode(GPIO45, OUTPUT); digitalWrite(GPIO45, LOW);`
2. 初始化 TFT 和 Sprite。
3. 在 Sprite 中完成整帧绘制。
4. 一次推送到 LCD。
5. 只有完成首帧后才点亮背光。

## 内存注意

- 必须检查 `createSprite()` 返回值。
- 需要明确启用 TFT_eSPI 的 PSRAM 使用属性。
- 不要为了动画再分配第二个 320×240 全屏缓冲。
- 大对象、截图临时缓冲和历史槽不要放到 `loopTask` 栈上。

## 调试建议

串口日志也属于“可见输出”。周期状态只低频打印，截图期间暂停日志读取线程，避免文本和二进制 RGB565 数据混在同一条 USB 流中。
