# 共享 I²C 与可选硬件降级

## 总线基线

GPIO15/16 是板载 ES8311 的 I²C 总线，后续 PCF8563 可以使用地址 `0x51` 与 ES8311 `0x18` 共存。每个器件的初始化和轮询必须有自己的状态，不应让可选模块成为整个系统的启动依赖。

## 可选硬件原则

- 模块不存在、NACK、VL 置位或字段非法时，屏幕、USB、音频和其它实验仍应工作。
- 初始化失败低频重试，不在主循环中忙等，也不持续刷日志。
- 读回数据必须做范围和格式校验，不能把 2000 年等默认日期当成有效时间。
- 运行中接入模块后，先完成完整探测和校验，再把状态切换为 ready。

## 接线检查

- 确认 3.3V 兼容性。
- 记录模块自带的上拉电阻，避免并联后阻值过低。
- 不可充电 CR2032 不得接入带充电回路的 RTC 模块。
- 共享总线出现锁死时，先断开新增模块验证基础器件是否仍稳定。
