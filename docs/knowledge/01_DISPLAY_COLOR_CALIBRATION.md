# ILI9341 颜色校准：BGR 与反色命令必须成套验证

## 问题

ILI9341 屏幕能点亮，但红、蓝互换，或者所有颜色接近互补色。只看“能显示文字”很容易误判已经正确。

## 已验证结论

- 这块 ES3N28P 的 LCD 使用 BGR 色序。
- TFT_eSPI 需要 `TFT_RGB_ORDER=TFT_BGR`。
- 厂商初始化要求打开 ILI9341 inversion，当前配置使用 `TFT_INVERSION_ON=1`，对应 `0x21`。
- BGR 和 inversion 是两个独立问题，不能只修其中一个。

## 推荐校准方法

1. 画出带文字的六色色块：红、绿、蓝、青、品红、黄。
2. 先检查红/蓝是否交换，再检查颜色是否整体变成互补色。
3. 固定 `setRotation(1)` 后检查文字方向和 320×240 逻辑坐标。
4. 用离屏画布截图检查固件实际 RGB565 内容，不能只依赖相机自动白平衡。
5. 把最终配置写入 `platformio.ini` 和 `docs/HARDWARE.md`，不要只留在临时示例里。

## 常见错误

- 直接照抄厂商示例的 RGB 配置，但没有确认当前板型。
- 以为颜色互补只是 RGB/BGR 顺序问题，实际上还缺少 inversion 命令。
- 把屏幕物理方向、MADCTL 色序和应用坐标方向混为一谈。
- 用持续清屏重绘的色卡测试造成闪烁，误以为颜色本身不稳定。

## 适用边界

这套结论适用于当前 ES3N28P 样机和 ILI9341 配置。换屏幕、换板型或换驱动库时仍需重新做六色色卡测试。
