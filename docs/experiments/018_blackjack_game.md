# 实验 018：PGOS 二十一点与事件动画

## 目标

在三款街机类游戏之外增加一款回合制牌桌游戏，验证规则状态机、顺序动画、
筹码资料和系统反馈可以在不扩大 Shell 职责的前提下组合成完整体验。

## 规则与资料边界

- `BlackjackEngine` 是不依赖 Arduino、LVGL 或 NVS 的纯 C++ 模块，负责单副
  52 张牌、洗牌、A 的软硬点数、庄家软 17 停牌、自然 Blackjack、要牌、
  停牌、双倍和结算。
- 剩余牌少于 15 张时在下一局前重洗；首版不加入分牌、保险和多玩家。
- 普通获胜返还 2 倍总下注，自然 Blackjack 返还 2.5 倍，平局退回下注。
- `BlackjackProfileService` 使用 `pgos_blackjack` schema 4 保存筹码、局数、
  胜负、平局、Blackjack、当前/最佳连胜和补助次数。
- 初始筹码 1000，下注提供 10 / 50 / 100 / 全押并统一使用 10 的倍数，避免
  3:2 产生半个筹码；筹码低于最低下注 10 时可领取 PGOS 补助，余额恢复到
  500。退出未结算牌局会返还本局下注。

## 事件动画与界面

- `BlackjackEngine` 只产生 `ShoeShuffled`、`CardDealt`、`HoleRevealed` 和
  `RoundSettled` 事件；`BlackjackApp` 顺序消费，动画期间忽略牌桌操作，
  系统 Back/Home 仍由 `AppManager` 处理。
- 使用状态栏下方 320×218 单一 LVGL 自绘面；绿色牌毡、米白牌面、红黑花色、
  金色选中态和 PG 牌背不创建每张牌对应的 LVGL 子对象。
- 发牌采用 220ms ease-out 位移动画并平滑重排已有手牌；隐藏牌使用 260ms
  横向压缩/展开模拟翻转；结算和补助使用定长筹码移动动画。
- RTC 有效时 18:00–05:59 使用更暗的夜场牌毡。A 确认，方向键或左摇杆选择，
  X 在玩家回合直接停牌，B/Home 使用系统返回语义。
- 发牌、翻牌和结算复用 `AudioService`；胜负请求分级手柄震动。
  `RgbService::flashFeedback` 只在用户已开启 RGB 时短暂覆盖输出，结束后恢复
  原灯效，不修改持久化设置。
