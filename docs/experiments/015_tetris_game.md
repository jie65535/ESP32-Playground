# 实验 015：PGOS 俄罗斯方块小游戏

## 目标

在已经验证的独立游戏绘制和 Xbox 手柄输入边界上加入一个可暂停、可重玩的俄罗斯方块小游戏。

## 当前实现

- App：`TetrisApp`，使用独立 LVGL 绘制面，10×20 棋盘和 9 像素格，适配 320×240 横屏状态栏下的可视区域。
- 方块：标准 I、O、T、S、Z、J、L 七种方块，7-bag 随机、旋转和简单墙踢。
- 规则：固定重力步进，软降、消行、等级和逐级加速；单行/双行/三行/四行分别按 100/300/500/800 × 等级计分。
- 输入：D-pad 左右移动、上方向旋转、下方向软降；左摇杆越过阈值时每次只接受一次动作，回中后才能再次触发，避免摇杆采样抖动造成连续误操作；A 启动/暂停/继续/重开，B/Home 返回桌面。
- 布局：10×20 棋盘保持屏幕正中，左侧显示 Top 5，右侧显示下一块、消行数、等级和当前最高分。
- 辅助显示：当前方块下方绘制半透明落点虚影，方便预判锁定位置。
- 快速操作：X 键执行硬降并立即锁定；下方向/下摇杆保持按住时连续软降。
- 反馈：普通落地播放短促游戏音并明显双马达震动；消除行播放更长的提示音，并根据消除行数增强震动强度和时长。消除时保留满行和堆叠，以最后落下方块的横向中心为起点错峰碎裂：每格拆成三块，带短白闪、横向飞散、轻微下坠和透明度衰减，约 320ms 后才压缩棋盘让剩余方块下落。
- 性能边界：粒子是绘制时按棋盘坐标和固定种子即时计算的矩形，不创建 LVGL 子对象、不分配堆内存；四行同时消除最多绘制 120 个短生命周期碎片，低刷新率下即使只显示少量关键帧也能呈现完整的“完整方块 → 裂片飞散 → 棋盘压行”状态变化。
- 供电注意：Xbox 手柄输入在电池电量较低时仍可能正常，但震动电机的峰值电流更高；验证震动前应接 USB 或确保电池电压充足。
- 持久化：`TetrisScoreService` 使用独立 `pgos_tetris` NVS namespace 保存五条最高分，不与贪吃蛇混用。
