# PlaygroundOS 功能清单

> 最后核对：2026-07-27
>
> 界面来源：`src/core/SystemKernel.cpp` 中的菜单定义与 App 注册表
>
> 用途：维护当前固件的用户功能；实现细节、资源预算和真机记录仍以对应实验文档为准

## 维护约定

- 本文按设备上的实际界面层级排列。新增、移动、重命名或删除页面时，应在同一次变更中更新本文。
- 页面只记录面向用户的功能，不在这里维护构建、烧录或测试状态。
- USB、PGOS Studio 等没有设备端独立页面的能力统一列在“界面之外的功能”。
- 详细实现、测试步骤和硬件记录链接到对应实验文档，避免在功能清单中重复维护。

当前桌面包含 3 个一级菜单、18 个前台功能页面：7 个游戏、7 个设置页和 4 个系统工具。

## 全局界面与输入

- 顶部 22px 状态栏常驻显示 `PGOS`、Wi-Fi、远程服务器、BLE 手柄和本地时间状态。
- 菜单使用上下移动焦点、确认进入；Back 逐级返回父菜单，Home 清空历史并回到桌面。
- 当前输入来源包括 USB 控制台、PGOS Studio TCP 控制和 Xbox BLE 手柄；游戏可直接采样摇杆、D-pad、按钮和扳机的连续状态。
- 屏幕息灭后，第一次有效输入只恢复背光，不继续执行本次页面或游戏操作。
- 列表页支持焦点居中滚动和前进/返回方向不同的页面转场；前台同一时刻只运行一个 App。

相关记录：[UI v2 与 LVGL](experiments/005_ui_v2_lvgl.md)、[Shell 架构与本地化](experiments/017_shell_architecture_localization.md)、[输入事件经验](knowledge/08_INPUT_EVENTS_AND_NONBLOCKING.md)。

## 游戏

### 1. 贪吃蛇

经典网格贪吃蛇，适合作为 PGOS 固定步进游戏和统一输入的基础验证。

- 20×12 棋盘；吃到食物后增长，禁止直接反向，撞墙或撞到自身结束。
- 初始移动间隔 220ms，每吃 4 个食物逐步加速，最快 90ms。
- D-pad 或左摇杆控制方向；A 开始、暂停、继续或重开。
- 保存独立 Top 5；吃食物和结束时提供声音，手柄连接时提供震动。

记录：[实验 014：贪吃蛇](experiments/014_snake_game.md)。

### 2. 俄罗斯方块

标准 10×20 俄罗斯方块，重点展示旋转、消行、等级加速和粒子演出。

- 包含 I/O/T/S/Z/J/L 七种方块、7-bag 随机、旋转和简单墙踢。
- 支持左右移动、上方向旋转、下方向连续软降、X 硬降，A 控制开始和暂停。
- 显示落点虚影、下一块、消行数、等级、最佳分和 Top 5。
- 消行按 100/300/500/800 × 等级计分，并播放碎裂、音效和分级震动反馈。

记录：[实验 015：俄罗斯方块](experiments/015_tetris_game.md)。

### 3. 打砖块

三关制 Breakout，使用连续挡板控制和固定步进碰撞，验证小球高速运动下的嵌入式物理边界。

- 3 条生命、3 个关卡；后续关卡包含空缺布局、双耐久砖块、更短挡板和更高球速。
- D-pad 或左摇杆连续移动挡板；A 开始、发球、暂停、继续或重开。
- 挡板命中位置影响反弹角度；包含连击、过关奖励和最高 178 px/s 的速度上限。
- 保存独立 Top 5；击砖、丢球和过关具有音效、碎片和震动反馈。

记录：[实验 016：打砖块](experiments/016_breakout_game.md)。

### 4. 超级马里奥

完整的 1-1 至 8-4、共 32 关横版平台战役。设备端只使用离线转换后的 C++ 地图和图块资源，不解析 CSV、XML 或 PNG。

- 标题页支持 WORLD 1–8、STAGE 1–4 选关，默认定位 NVS 继续点并显示最高分。
- 包含地上、地下、水下、城堡和奖励区，以及水管、藤蔓、弹簧、移动平台、滑轮、火焰棒、旗杆和 Bowser 桥战。
- 包含问号箱、普通砖、多金币砖、蘑菇、火花、星星、1UP、金币、火球、变身、受伤和死亡流程。
- 包含 Goomba、Koopa、Buzzy、Piranha、Blooper、Cheep、Lakitu/Spiny、Hammer Bro、Bullet Bill、Lava Bubble 和 Bowser 等差异化敌人。
- D-pad/左摇杆移动，上方向或 A 跳跃，下方向下蹲，X 暂停；保存继续关卡、通关状态和最高分。
- USB 提供 `platformer maptest [world-stage]` 和 `platformer mapnext`，用于无状态地图巡检。

记录：[实验 021：32 关战役](experiments/021_platformer_campaign.md)、[实验 022：参考行为对齐](experiments/022_platformer_reference_parity.md)。

### 5. 二十一点

单副牌 Blackjack，使用独立规则引擎和顺序事件动画实现下注、发牌、玩家操作、庄家回合与结算。

- 支持软/硬 A、自然 Blackjack、庄家软 17 停牌、要牌、停牌和双倍；不含分牌和保险。
- 下注档位为 10、50、100 和全押；普通胜利、自然 Blackjack 3:2，平局退回下注。
- A 确认当前操作，方向键选择，X 在玩家回合快速停牌。
- 初始筹码 1000；低于最低下注时可领取 500 筹码补助；保存筹码、胜负、Blackjack、连胜和补助次数。
- 包含发牌、翻牌、筹码和结算动画，并接入音频、震动和不修改灯光设置的 RGB 短闪。

记录：[实验 018：二十一点](experiments/018_blackjack_game.md)。

### 6. 扫雷

完整经典扫雷，提供标准三档和自定义棋盘；首击安全，并优先生成无需猜测即可解出的棋盘。

- 标准难度为 9×9/10、16×16/40、30×16/99；自定义范围为 8–30 列、8–16 行，雷数不超过 24%。
- A 翻格或 chord，X 插旗，Start 暂停；D-pad 和左摇杆支持连续八方向移动。
- 双击 A 自动展开当前可见信息能够证明安全的格子；双击 X 自动标记可证明为雷的格子，不读取隐藏雷图作弊。
- 提供生成检查、展开波纹、旗帜动画、暂停、胜负演出、记录页和“再来一局/难度”结算操作。
- 保存三档升序 Top 5、局数、胜率、连胜、自定义统计和最后设置；接入音频、震动和 RGB 反馈。

记录：[实验 023：扫雷](experiments/023_minesweeper_game.md)。

### 7. 2048

4×4 数字合并游戏，提供完整滑动动画、里程碑演出和一个隐藏的手柄自动走棋模式。

- 遵循单次合并规则，有效移动后按 90%/10% 概率生成 2/4；达到 2048 后仍可继续游戏。
- 方向键、D-pad 或左摇杆移动；A 开始、暂停、继续或在失败后重开，Start 也可切换暂停。
- 具有 145ms 滑动、合并弹性和新块弹出动画；达到 2048 时播放 1.8 秒金色里程碑演出。
- 保存 32 位最佳分、最高方块、完成局数和达到 2048 的局数；接入音频、震动和 RGB 反馈。
- 运行中长按 Xbox Y 900ms 启动隐藏的固定深度 Expectimax 自动走棋；持续按住会逐步加速，松开立即停止。

记录：[实验 024：2048](experiments/024_2048_game.md)。

## 界面之外的功能

### USB 控制台与主机工具

- 统一导航命令：方向、确认、插旗/快捷动作、暂停、Back、Home 和页面直达。
- 结构化状态与诊断：系统、I²C、时间、Wi-Fi、服务器、镜像、测速、手柄、麦克风和 RGB 状态。
- 无损 RGB565 截图：`tools/capture_screen.py` 校验请求、序号、长度和 CRC32 后导出 PNG/剪贴板。
- 麦克风导出：`tools/capture_microphone.py` 临时启动采集并导出 250–5000ms、8kHz mono PCM16 WAV。
- Platformer 地图巡检、Wi-Fi 凭据维护、服务器目标配置和吞吐实验均有独立命令。

入口与完整命令见 [USB 控制台经验](knowledge/04_USB_CDC_CONSOLE_AND_SCREENSHOT.md) 和 `help` 输出。

### PGOS Studio

- TCP 19000：方向、确认、返回、Home 等语义遥控，结构化状态、有界日志和控制 RTT。
- TCP 19001：独立上传/下载吞吐实验，支持状态和取消。
- TCP 19002：约 5 FPS 的 320×240 RGB565 完整帧镜像；连接时才维护 shadow framebuffer，并在连接建立时发送完整关键帧。
- Studio 不复制设备应用清单；新增页面后仍通过统一导航操作。

当前仍使用完整帧；keyframe + dirty rectangles、丢帧统计、UDP/mDNS 发现和录像属于后续功能，不计入当前功能清单。

### 后台系统能力

- LCD：原生 `esp_lcd_ili9341`、SPI2 40MHz、LVGL 9.5 和异步 DMA；失败时可回退同步刷新。
- 音频：ES8311/I²S 播放与麦克风采集由独立任务持有，App 只提交请求或读取快照。
- 连接：Wi-Fi、BLE 手柄、远程服务器、镜像和测速均使用有界队列、超时、取消或退避状态机。
- 时间：PCF8563 与 ES8311 共用 I²C 总线，模块缺失或读错时不阻塞其它系统。
- 持久化：显示、音频、RGB、手柄、网络、服务器及各游戏资料使用独立 namespace/schema，动态游戏过程不高频写 Flash。

## 暂不包含的规划项

以下项目仍在路线或待实验阶段，不属于当前功能清单：

- PGOS Studio 的 dirty rectangles、通用关键帧协议、UDP/mDNS 自动发现和录像。
- 实体按键/编码器统一输入、TF/扩展接口、ADC/功耗实验和 OTA 用户流程。
- 网络音频流、电脑画面反向推送到设备、局域网 HTTP/JSON 服务。
- 大语言模型的自由文本提示输入、P192 扩容和 8MiB 模型分区方案。
